# Pets

Общий код и рецепты приложений семейства «Pets» (Postman, Урфин и следующие). Интерфейс всех
приложений — на gpui; egui сюда не попадает.

## Крейты

| Крейт | Подход | Что внутри | Статус |
|---|---|---|---|
| `pets-commands` | действия пользователя | реестр команд: id, ключ названия, хоткеи по умолчанию, контекст; без UI | есть |
| `pets-gpui-windows` | платформа gpui | патч Windows-платформы gpui: кадры по запросу, живой ресайз, шейдеры в exe; пакет `gpui-pre-windows`, подключается через `[patch]` | есть |
| `pets-i18n` | тексты | Fluent, локаль ОС, `tr!`, проверка наборов и сырых строк; тексты `.ftl` — в приложении | есть |
| `pets-shell` | жизнь процесса | единственный экземпляр, tracing + журнал Windows, `fatal`; пути профиля и portable — позже | есть |
| `pets-ui` | визуальный язык на gpui | темы: роли цвета и метрики (как у Урфина), плотность 20/24/28/32, «как в ОС» на лету, темы в TOML с горячей перезагрузкой, политика HKLM; тосты с действием «Отменить» и история уведомлений; подтверждение одной строкой, команды → действия gpui — позже | есть (темы, тосты) |

Крейт появляется, только когда его использует хотя бы одно приложение. Предметное (почта, файлы)
остаётся в приложениях.

## Скилл

`skills/pets-architecture/SKILL.md` — исходник скилла `pets-architecture` (архитектурный базис). Правда — здесь,
в git; копия в Claude — резерв, после правки в репозитории её обновляют загрузкой файла.

## Рецепты

`docs/recipes/` — проверенные подходы, по одному на файл, с пометкой, где применимы. Это знания,
а не код: брать в приложение, если подходит его специфике.

## Стенд

`scripts/stand/` — общие скрипты стенда Windows для всех репозиториев Pets (рецепт «Гигиена диска»):
`setup-windows.ps1` (общий `CARGO_TARGET_DIR` на Dev Drive), `clean.ps1` (сборки, тестовые данные, временные
файлы), `clean-temp.ps1` (разовая чистка `%TEMP%`). Без `-Apply` только показывают.

## Подключение

```toml
pets-commands = { git = "https://github.com/Dicobraz/pets", rev = "<коммит>" }
```

Совместная правка приложения и `pets` — локальный `[patch."https://github.com/Dicobraz/pets"]` на путь,
в коммит не попадает.
