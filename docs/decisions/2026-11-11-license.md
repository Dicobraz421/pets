# Лицензия — проприетарная

(владелец, 2026-11-11)

1. Код pets, Урфина, Postman и The Post — проприетарный: «все права защищены», файл `LICENSE` в корне.
   Использовать, копировать, менять и распространять код без письменного разрешения правообладателя нельзя;
   коммерческие лицензии — отдельным договором.
2. В `Cargo.toml` — `license = "LicenseRef-Proprietary"`.
3. Версии, опубликованные до 2026-11-11 под MIT / Apache-2.0, остаются под прежней лицензией.
4. Чужой код остаётся под своей лицензией: `crates/pets-gpui-base` и `crates/pets-gpui-windows` (gpui,
   Apache-2.0) — со своими `LICENSE-APACHE`; зависимости — по своим лицензиям.
5. Бесплатная подпись SignPath Foundation (только для открытого кода) больше не подходит; подпись кода —
   отдельным решением.

Заменяет «Лицензия MIT OR Apache-2.0» в `skills/pets-architecture/SKILL.md`.
