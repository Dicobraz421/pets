# Крейт pets-update: обновление Урфина и Postman

(владелец, 2026-11-11; текст решения — Urfin `docs/decisions/2026-11-11-self-update.md`, Postman#503)

1. Обновление продуктов — один крейт `pets-update`, без UI. Потребители — Урфин и Postman; своих реализаций в
   продуктах нет.
2. Проверка — GitHub Releases репозитория продукта, раз в сутки и по кнопке, без данных пользователя; канал
   стабильный или бета. Версия не новее текущей не предлагается.
3. Скачивание и установка — только по согласию: MSI через `msiexec`, portable — замена файлов рядом с exe.
4. Подлинность — подпись minisign (ed25519) ключом, вшитым в программу; сертификата подписи кода нет. Подпись
   привязана к имени файла. Закрытый ключ — секрет репозитория, создаёт и хранит владелец.
5. Включено по умолчанию. Выключатель: настройка продукта (нет фоновых запросов) и политика
   `HKLM\Software\Policies\Aahz\<Продукт>`, `AllowUpdate = 0` (нет запросов вообще).
6. Это единственная сеть общего кода pets и единственное исключение из «офлайн»; телеметрии нет.

Заменяет в `skills/pets-dev/references/releases.md` строку «Сети в фоне нет: только по щелчку, в браузере».

## Технические выборы (агент, можно пересмотреть)

- HTTP — `ureq` с TLS Windows (SChannel) и системным прокси: корпоративные корни и прокси работают без настройки,
  своего набора корневых сертификатов нет.
- Формат подписи — minisign: готовая утилита для CI, проверка — `minisign-verify` (MIT, без зависимостей).
- Установку делает копия exe программы в режиме помощника (`run_helper`), а не отдельный exe и не `cmd`: нет
  второго бинаря в выпуске и нет разбора командной строки оболочкой.
- Ключ политик — `Aahz` (издатель), как в решении. У тем в `pets-ui` ключ `Software\Policies\Pets\<App>` —
  расхождение, свести отдельной задачей.
