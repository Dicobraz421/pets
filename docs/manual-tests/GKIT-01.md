# GKIT-01: ручная проверка на стенде (Windows)

Облако не запускает Windows-платформу: тесты `pets-gpui-windows` и кадры — здесь.

1. `cargo test --manifest-path crates/pets-gpui-windows/Cargo.toml --lib --features test-support -- vsync force_warp lazy_path image_sprite background pets_ shaders_are_embedded`
   — всё зелёное; `pets_fast_*` побитно равны старому пути (корпус строк, `--nocapture` — сводка).
2. Postman на пине этого коммита (GKIT-02): старт — без чёрной вспышки (окно появляется сразу с кадром приложения).
3. Живой ресайз за угол: содержимое тянется без чёрных полос, фон — цвет корня, не чёрный.
4. Простой: окно без анимаций — поток vsync спит (CPU процесса ~0 % в диспетчере задач).
5. `GPUI_FORCE_WARP=1` — окно рисуется (программный D3D).
6. Эмодзи в тексте (письмо, тема) — цветные: upstream 0.3.12 растрирует их на CPU, шейдер `emoji_rasterization` убран.
7. Строка с U+2028 (разделитель строк) в поле — на одной базовой линии (новое upstream разбиение).
8. Письмо: таблица сеткой и логотип подписи (сцены `compose-t306-*`, `compose-t307-*`) — блоки на месте,
   курсор перешагивает отведённые строки.
9. Перетаскивание вложения из окна, значок в трее, уведомление со звуком и щелчком — как до обновления.
10. `resize-check` и бенч приложения — не хуже замеров 0.3.9 (рецепты `bench.md`, `live-resize.md`).
