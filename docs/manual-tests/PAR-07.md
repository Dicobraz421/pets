# PAR-07: метка «из Интернета» при перетаскивании вложения (Windows)

1. Postman: открыть письмо с вложением (PDF и `.docx`), перетащить вложение на рабочий стол.
   Ожидание: в свойствах файла — «Этот файл получен с другого компьютера…» (флажок «Разблокировать»);
   `Get-Content <файл> -Stream Zone.Identifier` → `ZoneId=3`. `.docx` открывается в защищённом просмотре Word.
2. Перетащить то же вложение в окно нового письма Outlook. Ожидание: вложение добавлено, имя и размер те же.
3. Перетащить на FAT-флешку. Ожидание: файл скопирован (метки нет — у тома нет потоков; так у любого файла).
