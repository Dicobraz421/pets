## Где правда
1. `docs/decisions/` — решения владельца (приоритетнее всего).
2. `docs/CONTRACTS.md` — межкрейтовые контракты (менять только PR класса B).
3. Карточка задачи `docs/tasks/<ID>.md` и разделы из её `read:`. Остальное не читать без нужды.
4. Как запускать, снимки, стенд — `docs/DEV.md` (читать нужный раздел).

## Правила
- Полосы — `lanes.toml`; одна волна = одна полоса = один PR; `gh pr merge --auto` (очередь — merge-коммитом; цепочка — `--base <ветка нижнего PR>`).
- Проверки: локально `cargo fmt --all --check`, check/clippy своего крейта, nextest своих новых тестов (`-E 'test(...)'`), снимки затронутых сцен dev-сборкой.
  Полный clippy/nextest/doc-тесты — CI, не дублировать; падения — `gh run view --log-failed`.
